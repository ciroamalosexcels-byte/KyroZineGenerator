# Kyro Zine Generator

Editor de fanzines: páginas, imposición para imprimir y doblar, capas, texto, dibujo, PDF, y trabajar de a varios en vivo.

- **Usarlo en el navegador:** https://ciroamalosexcels-byte.github.io/KyroZineGenerator/
- **Programa para Windows:** [página de descargas](https://github.com/ciroamalosexcels-byte/KyroZineGenerator/releases/latest). Trae colaboración en la red local sin internet, y los `.kyro` se abren con doble clic.

Todo lo demás (cómo se arma, registro de cambios, pendientes e investigaciones) está en **[BITACORA.md](BITACORA.md)**.
